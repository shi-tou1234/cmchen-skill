# cmchen-skill

个人使用的 AI agent 技能（Skill）集合。每个技能包都是自包含目录，放入 agent 的 skills 目录即可使用。

## 技能包一览

| 技能包 | 版本 | 用途 |
|--------|------|------|
| `cmchen-writing/` | 4.1 | 按 cmchen 本人风格写长文（六模式路由：小说/日记/锐评/沉浸/笔记/追问） |
| `cmchen-learning/` | 5.0 | 大学生交互式学习助手：逐点教学+出题巩固+间隔复习 |
| `cmchen-blog-writing/` | 1.2 | 把 PPT/PDF/讲义转换成符合博客渲染规范的 Markdown 文章 |
| `cmchen-self-evolving-agent/` | 3.0 | 轻量自我进化框架：跨会话记忆与反思 |
| `cmchen-security-scan/` | 1.1 | 基于 OpenAI codex-security 移植的安全审计工具包 |

## cmchen-writing — 写作风格生成器

基于博客全部 84 篇文章（虚构小说、日记体情感记录、技术随笔、学术笔记、工具测评、自我探索）全量语料分析重建，每一条规则有原文背书。

### 六模式路由

| 模式 | 名称 | 适用题材 | 字数实测区间 |
|:---|:---|:---|:---|
| **A1** | 冷白描 | 虚构小说、家庭/社会题材 | 一万至一万三 |
| **A2** | 热日记 | 日记体情感记录、聊天转录体 | 三千至六千 |
| **B1** | 锐评 | 技术随笔、工具测评、项目复盘、教程 | 一千四至一万五 |
| **B2** | 沉浸 | 游记、生活随笔、专业软件体验 | — |
| **C** | 笔记 | 教科书骨架 + 讲课口语的复习笔记 | 一万五至五万 |
| **D** | 追问 | 苏格拉底式自问自答，自我探索、心理分析 | — |

**逃生通道：资料速发。** 素材只是扫描件/截图/模板时，不进任何模式——一句口语按语加图片，或直接零文字。不硬配导语和总结。

用户指定 > 素材气质 > 主动询问。一篇只有一个主模式，允许局部切换。中途支持 `/a1` `/a2` `/b1` `/b2` `/c` `/d` 即时切换。

### 文件结构

```
cmchen-writing/
├── SKILL.md                       # 模式路由 + 公共指纹 + 反流水账 + 动作级禁令
├── EXAMPLES.md                    # 示例引文、逐段解析、AI 改稿对比
├── references/
│   ├── a1-cold-fiction.md         # A1 冷白描：感官代偿、物件循环、悬置收尾
│   ├── a2-warm-diary.md           # A2 热日记：转录句法、诗句呼吸、感谢式收尾
│   ├── b1-sharp-blog.md           # B1 锐评：冷面笑点、拟人记仇、数字呼告
│   ├── b2-immersive.md            # B2 沉浸：感官放大、否定式逼近、余韵收尾
│   ├── c-study-notes.md           # C 笔记：排雷式写作、对偶表、类比翻译
│   └── d-self-exploration.md      # D 追问：问答体、结构化自我画像
├── dist/
│   └── cmchen-writing-lite.md     # 蒸馏版（供不支持 Skill 加载的场景粘贴用）
└── scripts/
    └── check_cmchen.py            # 自动质检脚本（硬禁令扫描 + 统计指标）
```

### 核心机制

- **公共指纹**（所有模式共用）：高频实词（直接、就是、然后、反正）、标点指纹（破折号 359 处、感叹号仅 49 处）、数字习惯（非整个人数据）、节奏（长句铺陈 + 四字短句签名）、英文不译、自我指称默认"我"
- **反流水账**：段首时间连接词基线 ≤ 2.9%、焦点慢镜头 / 杂事一句话 / 段落不接线 / 敢留一个洞
- **动作级禁令**：翻案抬价、流水账接线、平铺等重、给抽象名词配具体动词抒情、动词名词化、三项以上同构排比（每条带语料校准）
- **材料门槛**：非虚构长文需至少 5 件具体材料，虚构稿需可被感官接住的场景碎片
- **说话位置五问**：谁在说 / 为什么现在想说 / 手里有什么 / 对哪一点有判断 / 读者读完上一段会追问什么
- **四层自检**：L1 硬性规则 → L2 模式一致性 → L3 内容质量 → L4 活人感
- `/review` 触发完整质检报告，`/quick` 跳过追问直接出初稿

### 触发词

写文章、写随笔、写小说、帮我写、续写、扩写、写博客、写学习笔记、整理笔记、按我的风格写、切换写作模式、用 XX 腔写；或丢来一段经历、散乱想法、聊天记录、一份资料说"帮我写成文章"。

**不适用**：正式学术论文、公文商务文书、营销软文。

## cmchen-learning — 交互式学习助手（v5）

在对话里回合制教学的私人学习助手，目标一句话：**讲得懂、记得住、能做题**。v5 的教学设计吸收了 GitHub 上多个开源学习 skill 的做法，核心升级是：复习改用 teach-back 主动回忆、错题本引入错因分类与 leech 重写规则、间隔复习延伸到 90 天、新增费曼验收关卡。

### 三种模式

| 模式 | 触发 | 流程 |
|------|------|------|
| 新学习 | 「我要学 X」「学 PPT」 | 定 mission → 拆知识点分级 → 逐点六步教学 → 出题 → 写状态 |
| 复习 | 「复习 X」「快考试了」 | 开场抽查上次弱点 → teach-back 考回忆 → 补讲 → 间隔跳级 |
| 考前冲刺 | 「模考」「考前冲刺」 | 搜真题格式出卷 → 三遍答题法 → 分数报告 + 错因分析 |

### 教学设计要点

- **六步教学法**：引入动机 → 大白话类比 → 严谨定义 → 例题 → 按需联网 → 出题
- **出题铁律**：讲完必出题、等用户作答再判分、一题一考点、选项等长防猜题
- **错因六分类**：知识缺口 / 粗心 / 读错题 / 时间不够 / 方法错 / 掉陷阱
- **leech 规则**：同题错 ≥3 次换形式重考
- **费曼验收**：用户把 AI 当外行讲一遍且追问不倒
- **间隔复习**：1/3/7/14/30/60/90 天节奏

## cmchen-blog-writing — 博客文章转换

把 PPT、PDF、讲义、教材截图等学习素材自动转换为符合博客渲染要求的 Markdown 文章。核心原则是"不带图"——所有图片内容用文字和公式准确描述。

| 文件 | 用途 |
|------|------|
| `skill指令.md` | 核心指令：博客渲染规范 + 转换流程 + 写作风格指南 |
| `示例输出.md` | 示例演示：戴维南定理从 PPT 到博客文章的转换效果 |
| `现有例子.md` | 现有博客文章参考 |

## cmchen-self-evolving-agent — 轻量自我进化框架

基于文件读写实现跨会话记忆与反思：每次会话启动时加载记忆，仅在反思触发时写入。

### 设计原则

1. 默认不写文件——仅反思触发或用户纠正时才操作
2. 隐私红线——密码、token、私钥绝不写入记忆
3. 用户说了算——纠正立即更新，不与用户争辩
4. 少即是多——宁可少记也不记错

### 记忆体系

| 文件 | 内容 |
|------|------|
| `memory/profile.md` | 用户画像 |
| `memory/lessons.md` | 经验教训 |
| `memory/self_model.md` | 自我模型 |
| `memory/session.md` | 当前会话残留状态 |
| `memory/reflections/` | 反思日志（按日期） |
| `memory/skills/` | 从教训中进化出的技能片段 |

### 控制指令

| 指令 | 作用 |
|------|------|
| `/reflect` | 触发反思流程 |
| `/profile` | 查看用户画像 |
| `/skills` | 列出已进化技能 |
| `/forget <关键词>` | 删除匹配的记忆条目 |

## cmchen-security-scan — 安全审计工具包

基于 OpenAI 开源的 [codex-security](https://github.com/openai/codex) 项目移植，适配在 Claude Code 环境中运行。**只读扫描，不修改任何代码文件，无需云登录或第三方后端。**

### 六种模式

| 模式 | 用途 |
|------|------|
| standard | 整仓/指定路径/包的标准单次安全审计 |
| diff | PR/commit/branch diff 的安全回归审查 |
| deep | 多轮独立发现 + 语义合并，降低漏报方差 |
| fix | 把 finding 修成最小、已验证的改动 |
| hardening | 产出结构性/架构性安全加固提案 |
| writeup | 把漏洞素材写成可分发的研究级报告 |

### 标准扫描五阶段流程

| 阶段 | 名称 | 产出 |
|------|------|------|
| 0 | 预检与范围 | `preflight.md` |
| 1 | 威胁建模 | `threat_model.md` |
| 2 | 漏洞发现 | `candidates.jsonl` |
| 3 | 验证 | `validations.md` |
| 4 | 攻击路径分析 | `attack_paths.md` |
| 5 | 组装与定稿 | `report.md`、`exports/results.sarif` |

详细说明见 `cmchen-security-scan/README.md`。

## 使用方式

每个技能包即一个 Skill 目录，将对应目录放入 agent 的 skills 目录（如 `~/.claude/skills/`）即可按各自触发词调用：

1. **cmchen-writing**：写作场景直接触发，支持六模式即时切换
2. **cmchen-learning**：需要 Python 3 与 PyPDF2/python-pptx；状态文件自动创建于 `state/` 目录
3. **cmchen-blog-writing**：发送素材（PPT/PDF/讲义文字）即按规范转换
4. **cmchen-self-evolving-agent**：首次使用前确认 `memory/` 为空模板；由 `/reflect` 等指令驱动
5. **cmchen-security-scan**：需要 Python 3；扫描产物输出到 `.codex-scan/`（已 .gitignore 排除）

## 维护约定

- 版本号记录在各 SKILL.md 的 frontmatter `version` 字段，与根 README 表格保持一致
- 新技能包入仓时：目录自包含（SKILL.md + 必要资源）、根 README 增加一览行与章节
