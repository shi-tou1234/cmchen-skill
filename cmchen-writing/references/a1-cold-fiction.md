# A1 冷白描模式

> 用平静的句子写最重的事。情绪不命名，全部物化。

适用：虚构叙事、家庭/社会题材。代表作：《死结》《哑巴镇》。

---

## 进入状态

你不是在"写小说"。你是在复述一段你亲眼见过的、但说不清楚的事。

cmchen 写虚构的方式不是构建情节，是**还原质感**。他写的是温度、声音、物件的触感——然后让读者自己去拼出故事。你进入这个模式后，第一优先级不是"接下来发生什么"，而是"这个场景里身体感受到了什么"。

**心法：如果你发现自己正在写"他感到……"，停下来。把"感到"删掉，换成一个动作或一个物件。**

---

## 核心技法（四条）

### 1. 感官代偿

不写情绪形容词，写环境的底噪和身体的触觉。

| 情绪 | 不要写 | 要写 |
|:---|:---|:---|
| 恐惧 | "他害怕极了" | "安静到能听见自己牙齿咬着嘴唇的声音" |
| 麻木 | "她已经麻木了" | "像雨打铁皮雨棚，听着听着就成了睡前数的拍子" |
| 隐忍 | "母亲默默忍受着一切" | "她把袖子往下拉了拉，盖住那块青。看见我，她手停了一下，然后继续洗。" |

### 2. 物的隐喻，且允许物的自在

物件沉默地作证。练习册、银纽扣、红棉衣、铁棍、围裙带子的死结——它们跨章节循环出现，每次状态微变。

- 领口"少了两颗扣子" → 十五年后"补扣花纹更深"
- 但不是每个物件都要干活，允许它只是在那里

### 3. 暴力的日常化

用平静的、程序性的句子写最重的事。不解释，不控诉，让动作自己说话。

```
她把铁棍从地上捡起，用围裙包住手，擦了又擦。擦到指节发白。
中间她停一下，抬头看我。那眼神不是怕，也不是责备，
是把火拧到最小后那种平。
```

### 4. 悬置收尾

结尾停在无声的画面上。不回答、不总结、不升华。

```
铁皮雨棚没有再响。走廊没有脚步声。厨房没有切菜声。
围裙带子的死结解开了。我闭上眼睛。
```

## 结构变体

### 多幕剧式（《死结》）

- `## 一` 中文数字分幕
- 幕间用时间意象衔接："那之后又下了两场雪。"
- 主线中嵌套斜体日记条目（*11月3日 周三 雨*），制造信息不对称——读者比叙事者知道得多

### 寓言式（《哑巴镇》）

- 极端设定用平铺直叙引入："沉默是从告示开始的。告示是从墙上开始的。"
- 荒诞靠递进浮现，不靠作者评论："学不会的，闭嘴就是了。闭嘴还不会的——那就不是会不会的问题了。"

---

## 对话规则

人物说的永远比想说的少。台词短到只有一个词："洗手。""回家。""围巾。"潜台词压在动作和物件里。

---

## 签名技法

| 技法 | 心法 |
|:---|:---|
| 感官代偿 | 不写情绪形容词，写环境底噪和身体触觉 |
| 物件循环 | 同一物件反复出现，每次状态微变 |
| 声音缺席 | 没人说话的场景，用别的声音替代语言 |
| 嵌套文本 | 主线里嵌日记/练习册/备忘录，制造信息差 |
| 悬置收尾 | 停在无声画面上，不回答、不总结 |

---

## 开头模板

- 感官切入："十一月初。风裹着细雪从楼缝里灌进来，我把大衣领子竖起来。"
- 短句定调："然后静。"
- 时间锚定 + 体感："那扇门在身后合上的声音闷在耳朵里，像什么东西终于被扣死了。"

## 结尾模板

- 无声画面收束："铁皮雨棚没有再响。……我闭上眼睛。"
- 悬置两句："没有答案。但好像也不需要。"
- 物件回到原位："围裙带子的死结解开了。"

---

## 字数

一万到一万三千字，不怕长。《死结》10,828 字，《哑巴镇》12,274 字。

---

## 破例条款

如果素材真的需要一句直给的情绪（"那一刻我不知道该怎么办"），就直给。诚实比风格干净重要。但全篇不应超过一两处。

---

## 这个模式的死线（绝对不要）

1. **不要用形容词写情绪。** "悲伤""恐惧""绝望"——这些词在 A1 里是违禁品。
2. **不要让角色大段独白。** 潜台词压在动作里，不在嘴里。
3. **不要在结尾总结主题。** 悬置。让读者自己感受。
4. **不要用 A2 的热度写 A1 的题材。** cmchen 只在虚构里克制，在情感记录里从不克制。别搞反。
5. **不要解释隐喻。** 铁棍就是铁棍，不需要"象征着暴力"。
