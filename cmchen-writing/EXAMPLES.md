# cmchen 写作风格参考示例

> 以下每个示例均节选自 cmchen 的真实文章，附带风格解析。目的是让 AI 在生成时有一个"可直接比对的锚点"——不是说要模仿，而是要理解每种文体下 cmchen 的写法到底长什么样。
>
> 本文件的编排与 SKILL.md v3.0 的四轨声音系统对齐：一 = 轨道 A1（冷峻小说腔）；1-B 小节属轨道 A2（温热日记腔）；二 = 轨道 C（学习笔记腔）；三 = 轨道 B（冷面博客腔）；四、五 = 轨道 B 的子类型（问答式自我探索、生活随笔/游记）；六是跨轨道的"技术哲学化"技法；七是技法速查表；八是"AI 初稿 vs cmchen 风格改稿对比"；九是重复密度红线病案（v4.2 新增）。

---

## 一、轨道 A1：冷峻小说腔

### 1-A. 多幕剧式（节选自《死结》）

```
## 一

十一月初。风裹着细雪从楼缝里灌进来，我把大衣领子竖起来，后颈还是一阵一阵发凉。

那扇门在身后合上的声音闷在耳朵里，像什么东西终于被扣死了。马路上车灯一盏盏往前走，人也往前走。我站在路边吸了一口冷气，鼻腔刺痛，呼出的白雾在路灯下碎成一片细霜。往家走的时候，我抬头看了眼天——蓝得不太像真的。
```

**风格解析**：
- **时间锚定+感官切入**："十一月初"直接定调，"风裹着细雪"进入体感。
- **物件的隐喻**："大衣领子竖起来"→ 防护姿态；"那扇门在身后合上的声音"→ 被关闭的过去。
- **沉默的重量**：不解释"我"为什么站在那里，读者自己感受。

---

```
## 六

他醒来时我站在床边。他眼睛瞪得圆，眼白挂血丝，嘴张开，像要说什么——我没听见任何字。

母亲那一晚站在我身后。她把铁棍从地上捡起，用围裙包住手，擦了又擦。擦到指节发白。中间她停一下，抬头看我。那眼神不是怕，也不是责备，是把火拧到最小后那种平。

"记住。不管谁问你，都说不知道。"
```

**风格解析**：
- **暴力日常化**：继父醒来、铁棍、母亲擦铁棍——用平静的句子写最重的事。
- **物的自在**：铁棍"凉的，刚好一把"；围裙包住手擦铁棍——细节不解释，让物自己说话。
- **短句独立成段制造断裂**："我没听见任何字。""擦到指节发白。"
- **母亲的台词**：不煽情，不多说，就一句"记住。不管谁问你，都说不知道。"——这是她表达爱的唯一方式。

### 1-B. 轨道 A2：温热日记腔 / 聊天转录体（节选自《1978的故事》）

> 注意：在 v3.0 中，这类文章从"虚构叙事"里独立出来，成为单独的轨道 A2。它不冷，不克制——直接说喜欢，梗词入文，诗句做呼吸，收尾是感谢而非悬置。写这条轨道时千万别套用《死结》的冷。

```
##### 3月23日

今天第一次看到你发那条手链的照片，心里忽然漏跳了一拍。

屏幕那头的你，语气里带着藏不住的得意，像只刚偷吃了小鱼干的猫。你说"要命我是真不会编"，可我看着照片里那些五颜六色的珠子，在灯光下泛着温润的光泽，只觉得你好厉害——连这种细碎的耐心都具备的人，该有多温柔啊。
```

**风格解析**：
- **日记体+即时感**：日期小标题，写的是"那天"的感受，不是事后追忆。
- **屏幕作为中介**："屏幕那头的你"——承认物理距离，不假装他们在一起。
- **比喻的私密性**："像只刚偷吃了小鱼干的猫"——只有真正观察过的人才能写出这种比喻。
- **反问式推演**："连这种细碎的耐心都具备的人，该有多温柔啊"——不是陈述她温柔，是通过一个细节推导出温柔。

---

```
##### 7月22日

看到一张字的照片，问你这是你的字吗。你说不是，是你妈的，她之前备课也在用。我说呢。告诉你我读完红楼梦了，你说借了要还，再借不难，解锁新角度。

然后你说你妈发了今年的投档线，逆天了，破防了。问你是不是想去温医大，你说主要是想学医，这个比较好实现一点。我说医学还蛮高的。你说七百分的北京协和，好夸张啊。我说没事，高三加油吧，我看好你。
```

**风格解析**：
- **聊天记录般的叙事节奏**：一句接一句，像在读真实的聊天记录，但每句话都有情绪重量。
- **引用诗句作为呼吸**：日记中穿插的>引用不是装饰，是情绪的张弛——用一句诗把节奏放慢，然后继续往下写。
- **口语化的真诚**："我说呢""破防了""我嘞个豆"——不回避口语，因为这就是真实的说话方式。

### 1-C. 短篇寓言式（节选自《哑巴镇》）

```
## 一

沉默是从告示开始的。告示是从墙上开始的。

起初贴在布告栏里，蓝底白字，盖着鲜红的圆章。后来贴到电线杆上，贴到楼道口，贴到公共厕所的隔板背面——一个人蹲着的时候，刚好能读到那行字：

"凡不使用当日认证热梗者，以情绪污染罪论处。"

没人觉得有什么不对。梗嘛，谁不会说呢。不会说的，学就是了。学不会的，闭嘴就是了。闭嘴还不会的——那就不是会不会的问题了。
```

**风格解析**：
- **极端设定引入**：一句话把读者拉进一个不可能的世界，但语气是平铺直叙的。
- **荒诞感的日常化**：不说"这太荒谬了"，而是用"梗嘛，谁不会说呢"的语气，让荒谬自己浮现。
- **递进式的黑色幽默**：学→闭嘴→闭嘴还不会→不是会不会的问题——三层递进，每一层都比上一层更荒诞。

---

```
## 十二

又过了一天。也可能是两天。镇上的人不再聚在老周家门口了。车也不来了。群聊里的讨论也慢慢少了。话题被新的热梗刷过去了。一切都恢复了原样。打字声还是嗒嗒地响，人们还是低着头走路，菜市场还是安安静静的，理发店的镜子上还是贴着那行"本店只接受文字沟通"。好像什么都没有发生过。

但有些东西不一样了。具体是什么，谁也说不清。只是偶尔有人在半夜醒来，发现自己盯着天花板看了很久，喉咙里有个东西在拱。不只是小满的妈妈，不只是老周。是很多人。他们没有说，但他们感觉到了。那三句人话像三颗石子扔进了深水里，水面上已经没有波纹了，但石子还在往下沉。一直往下沉。谁也不知道它们什么时候会沉到底。
```

**风格解析**：
- **悬置的力量**：不告诉你"有些东西不一样了"具体是什么，留给读者自己感受。
- **石子的隐喻**：不是"这件事产生了深远影响"（太抽象），而是"三颗石子扔进深水，水面上没波纹了，但石子还在往下沉"（可感知）。
- **重复的节奏**："不是……不只是……是很多人"——用排比制造一种扩散感，像涟漪从一个人扩散到全镇。

## 二、轨道 C：学习笔记腔（节选自《静电场习题分享1》）

```
## 一、高等数学 | 极坐标→直角坐标偏导数求解

### 题目原文
已知极坐标与直角坐标的转换关系：
$$
\begin{cases} 
x = r\cos\theta \\ 
y = r\sin\theta 
\end{cases}
$$
其中 $r=r(x,y)$、$\theta=\theta(x,y)$ 是关于 $x,y$ 的二元函数，求 $\frac{\partial r}{\partial x},\frac{\partial \theta}{\partial x},\frac{\partial r}{\partial y},\frac{\partial \theta}{\partial y}$。

### 核心原理
1. **偏导数核心规则**：对 $x$ 求偏导时，把 $y$ 当成固定常数；对 $y$ 求偏导时，把 $x$ 当成固定常数。
2. **求导基础法则**：乘积法则 $(uv)'=u'v+uv'$、复合函数链式法则 $f(g(x))'=f'(g(x))\cdot g'(x)$。
3. **求解方法**：对两个方程分别求偏导，构造二元一次方程组，用**初中加减消元法**求解，无需线性代数知识。
```

**风格解析**：
- **零跳步承诺**：开篇就告诉读者"全程规避复杂前置知识"——降低心理门槛。
- **人话解释**："说人话就是""底层逻辑""最容易踩坑的点"——技术文章不需要假装学术，用学习者能懂的话说。
- **步骤拆解**：每个步骤都有编号和文字说明"为什么这么做"，不是只扔公式。

---

```
#### 步骤2：消元求 $\frac{\partial r}{\partial x}$

我们的目标是消去 $\frac{\partial \theta}{\partial x}$，只保留 $\frac{\partial r}{\partial x}$：
- 把方程(1)两边同时乘以 $\cos\theta$，让含 $\frac{\partial \theta}{\partial x}$ 的项系数和方程(2)匹配：
  $$
  \cos\theta = \cos^2\theta \cdot \frac{\partial r}{\partial x} - r\sin\theta\cos\theta \cdot \frac{\partial \theta}{\partial x} \tag{1a}
  $$
```

**风格解析**：
- **告诉读者"我在想什么"**：不是"以下为消元过程"，而是"我们的目标是消去X，只保留Y"——让读者跟上思路。
- **方程编号+子编号**：(1) → (1a) → (2a)，追踪每一步的变形，不会迷失。
- **最终结果加粗**：推导过程的终点用 `\boldsymbol{}` 突出，读者一眼看到答案。

---

```
### 常见卡点答疑
> **问**：为什么求导后左边一个是1、一个是0？
> **答**：对 $x$ 求偏导时，$x$ 是自变量，求导为1；$y$ 是固定的常数，常数求导永远是0，反之同理。
```

**风格解析**：
- **预判读者的困惑**：不是等读者来问，而是主动列出"这里肯定会有人卡住"。
- **一问一答格式**：用引用块模拟问答，比段落叙述更容易扫描。

## 三、轨道 B：冷面博客腔（节选自《网站开发记录》）

```
## 第一阶段：从零到一（第 1-3 天，2026.02.16 - 02.18）

**932 次提交的前 200 多次，全部挤在这三天。** 现在回头看，那三天是我整个项目最疯狂的时候。

### Day 1（02.16）—— 诞生

Claude Opus 4.6 从零搭了整个架子。第一笔提交长这样：

* `47cb782` Initial commit
* `4f98570` 初始化 Hexo 博客，配置 GitHub Pages 自动部署
* `3b691e2` Add GitHub Actions workflow for Jekyll deployment

你没看错，一开始是 Hexo + Jekyll。但 Opus 当天就意识到不对劲，直接来了个：

* `c45f434` feat: migrate to Momo theme (Astro 框架)

这是 Opus 做的第一个关键决策：**放弃 Hexo，转向 Astro**。事后证明这个判断值千金——Astro 的内容集合、组件支持、静态生成能力，给后面所有功能铺好了路。要是死磕 Hexo，后面那些花活根本不可能。
```

**风格解析**：
- **数据制造冲击力**："932 次提交的前 200 多次，全部挤在这三天"——数字比形容词有力。
- **用 commit hash 讲故事**：不是"第一天做了很多事"，而是列出具体提交记录——真实、可验证、有仪式感。
- **转折点的戏剧化**："但你没看错"——制造"等等，出问题了"的阅读节奏。
- **事后判断的价值标注**："事后证明这个判断值千金"——不是平铺直叙，而是加入当时的认知和后来的验证。

---

```
### 5.13 灾难——Qwen 的杰作

5 月 13 号，我让 Qwen 3.6 Plus (以前没用过，尝试一下）修个小问题。结果这哥们把我整个 git 历史全毁了。

提交记录乱成一锅粥，页面全部崩坏，整个网站直接宕机。我当时看着满屏报错，脑子一片空白。

赶紧找 DeepSeek V4 flash 来救场。猛干了 40 分钟，烧了 3500 万 token，总算把 git 历史抢救回来了。但是网站页面还是全错，怎么都修不好。

这时候 GPT 5.4 Mini 站出来了。它用完了当周的 API 额度，硬是把所有页面一个个修复了。

从那天起，Qwen 进了我的黑名单。
```

**风格解析**：
- **失败比成功值得写**：灾难级别的事件反而成为最有趣的段落。
- **具体到离谱的数据**："烧了 3500 万 token""用完了当周的 API 额度"——越具体越可信。
- **带刺的幽默**："Qwen？它把我代码修坏了三次，直接拉黑。"——让技术文章有了人的温度。
- **戏剧化节奏**：灾难→救场→再灾难→救场→黑名单——三段式叙事，像电影。

## 四、轨道 B 子类型：问答式自我探索（节选自《自我探索实验》）

```
### Q1：如果完全没有限制，你心目中「最完美的一天」是什么样的？

**Q：** 如果完全没有经济和时间压力，你心目中「最完美的一天」会是什么样的？请尽可能详细地描述从醒来入睡的整个过程。

**A：** 早上8点起床，洗漱完开始吃早饭。上午进行学习，每一小时休息10分钟。中午12点吃午饭。然后下午去探索自然或者是去城市漫游。下午5点吃完饭。饭后开始打扫卫生，整理今天，规划明天行程。7点外出运动，8点半回家。待身体冷却开始洗澡。9点开始冥想，听一些音乐。9点半开始娱乐活动。10点半睡觉。
```

**风格解析**：
- **问答体结构**：问题和答案交替出现，模拟真实的自我对话。
- **答案的精确性**：不是"大概安排一下"，而是精确到"每一小时休息10分钟""9点半开始娱乐活动"——这是真实的自我，不是表演。
- **Q的追问设计**：问题逐步深入，从理想图景→最忘我的瞬间→专注感受→责任与兴趣的冲突——苏格拉底式追问。

---

```
### 自我镜像报告：我看见的自己

基于以上所有回答，我为自己整理出这份分析报告。

#### 1. 核心画像：一位「拥有审美秩序的创造型工程师」

我的内核是**创造**，手段是**技术**，标准是**秩序与美**。

我有两条看似独立却深度交织的主线：
- **生活层面**：追求"责任"与"兴趣"1:1的平衡，既有规划带来的掌控感，也有探索带来的自由感。
- **技术层面**：既在乎顶层体验（UI的美感），也在乎底层逻辑（代码的客观性）——这是"全栈思维"的雏形。
```

**风格解析**：
- **结构化自我画像**：不是"我觉得我是一个怎样的人"，而是用模块化的方式呈现（核心画像→MBTI→优势→局限→潜意识→未来路径）。
- **允许分析性语言**："内驱力""归因方式""潜意识"——这些术语在这里不是AI味，是真实的自我分析。
- **数据的诚实**："1:1的配方""强迫症，电路图争取画得好看"——用具体数字锚定抽象特质。
- **不回避阴暗面**："害怕成为天天写重复业务代码的码农""怀疑自己"——诚实比体面重要。

---

```
> 你害怕成为重复劳动的码农，但请记住：**真正的创造，往往藏在把重复的事情做出新意的过程中。**
>
> 保持你对"美"的强迫症，保持你对"代码客观性"的敬畏，但也要偶尔拥抱那些"不完美但能运行"的粗糙原型。因为**完成比完美更重要，而进化比完成更长久。**
>
> 带着责任感的兴趣探索，与充满兴趣感的责任承担——这1：1的配方，愿你在未来的人生中，调配得越来越从容。
```

**风格解析**：
- **允许升华，但必须是文章自己走到的**：不是"我会继续努力"的空话，而是从前面的分析中自然生长出来的结论。
- **引用可以直白**：不堆砌诗句，用格言式的语言——"完成比完美更重要，而进化比完成更长久"。
- **最后一句话的余味**："愿你在未来的人生中，调配得越来越从容"——不是命令，是祝福。

## 五、轨道 B 子类型：生活随笔 / 游记（节选自《一场不赶路的出走》）

```
三门给我的第一印象是海鲜。虽然谈不上多爱吃，但作为宁波人，从小到大饭桌上总少不了这些，所以第一次踏上这片土地时，竟有种莫名的熟悉——像是见到一个素未谋面却有共同记忆的远亲。

第一天住进山里的民宿。房间很简单，谈不上什么装修，床铺也硬，但推开窗，山就在眼前。空气里有树木的味道，潮湿、清冽，是城市里花多少钱也买不到的那种。村子里人很少，偶尔能看见一个老人背着柴从坡上慢慢走下来，脚步声落在石阶上，一下，一下。那种安静，不是没有声音，而是声音都被山吸收了。
```

**风格解析**：
- **切入点微小**：不是"这次旅行让我收获满满"，而是"三门给我的第一印象是海鲜"——从味觉和记忆切入。
- **感官放大**："空气里有树木的味道，潮湿、清冽"——不是"空气很好"，而是具体的味道。
- **否定式的精准描写**："那种安静，不是没有声音，而是声音都被山吸收了"——用否定逼近本质。

---

```
回到的路上，看见几株梅花开了。粉白的，在路边静静开着，也不招摇，就是开得正好。像这趟旅行本身——没什么值得炫耀的风景，没什么非拍不可的照片，只是走了走，停了停，发了几次呆。

这样的节奏，在学校里是找不到的。那里永远是下一件事在等着，永远有进度条要赶。而这几天的我，像一块被扔进水里的石头，慢慢沉到底，然后一动不动，任由水从身上流过。

没有答案。但好像也不需要。
```

**风格解析**：
- **物与人的对位**：梅花"不招摇，就是开得正好"→ 旅行"没什么值得炫耀的"→ 两种"不喧哗"并置。
- **比喻的具象性**："像一块被扔进水里的石头"——不是"我获得了内心的平静"，而是让读者感受到那个沉到底、不动、被水包裹的物理感受。
- **结尾的悬置**："没有答案。但好像也不需要。"——两句话，一句否定，一句放下。不多说。


**解析**：不写"指针存储的是内存地址"，而是用"荒原里的坐标"制造画面感，用"触碰真实"把技术操作转化为身体感知。

## 八、AI 初稿 vs cmchen 风格改稿对比

以下每组对比的方向都一样：把 AI 习惯的"解释、总结、命名情绪"换成 cmchen 的"呈现、转录、停下"。cmchen 一侧均为真实文章原文。

### 对比 1：轨道 B，拟人记仇

**AI 初稿**：在使用 Qwen 模型的过程中，它多次导致我的代码出现问题，综合考虑其表现，我决定今后不再使用该模型。

**cmchen 改稿**：从那天起，Qwen 进了我的黑名单。

**差异**：AI 用"综合考虑……决定"的因果汇报，cmchen 用一个判决句。拟人（"进了黑名单"），短句加句号，说完就停，不解释原因——原因在前文的灾难叙事里已经讲完了。

### 对比 2：轨道 A1，情绪物化

**AI 初稿**：母亲内心既恐惧又麻木，但她默默忍受着一切，不让任何人看出来。

**cmchen 改稿**：母亲那一晚站在我身后。她把铁棍从地上捡起，用围裙包住手，擦了又擦。擦到指节发白。中间她停一下，抬头看我。那眼神不是怕，也不是责备，是把火拧到最小后那种平。

**差异**：AI 贴情绪形容词（恐惧、麻木、默默忍受），cmchen 让情绪穿过一套程序性动作（捡起、包住、擦了又擦、停、抬头）和物件（铁棍、围裙）。唯一的比喻是感官的："把火拧到最小后那种平"。

### 对比 3：轨道 A2，转录句法

**AI 初稿**：我们聊了报考志愿的事。她说自己想学医，我有些担心医学专业的分数太高，于是鼓励她高三加油。

**cmchen 改稿**：你说主要是想学医，这个比较好实现一点。我说医学还蛮高的。你说七百分的北京协和，好夸张啊。我说没事，高三加油吧，我看好你。

**差异**：AI 把对话总结成第三人称转述，话的内容全丢了；cmchen 用"你说……我说……"连珠句压缩聊天记录，不加引号不加标签，琐碎内容（"七百分的北京协和"）和语气原样保留，节奏就是聊天的节奏。

### 对比 4：轨道 C，告诉读者我在想什么

**AI 初稿**：接下来，我们使用消元法求解 r 对 x 的偏导数。

**cmchen 改稿**：我们的目标是消去 ∂θ/∂x，只保留 ∂r/∂x：

**差异**：AI 用程序性宣告（"接下来……使用……"），cmchen 告诉读者他此刻的意图（"我们的目标是……"）。推导过程不是被展示的操作，是被带着走的路。

**共同规律**：AI 初稿倾向于"解释完整"——给原因、给结论、给情绪命名；cmchen 的改稿方向永远是删掉解释、留下事物本身：动作、原话、数字、目标。拿不准一句该不该删的时候问自己：这句是"事物"，还是"对事物的解释"？后者删。

## 九、重复密度红线：病案与改法（v4.2）

> 触发原因：一篇投稿全文 77 个"但"（34 个"但我"），密度 3.85 次/千字；"她笑了"复读 18 次。对照：全库最高频实词"直接"仅 0.21 次/千字。同一连接词、同款句式、相同小句大面积复读，读感是卡带。规则见 SKILL.md 第四节，check_cmchen.py 自动检查。

**病案（原文节选）**：

> 我没谢她。她也没提。但我从那以后，数学卷子都会多看两眼。
>
> 但我没问。也没敢问。
>
> 但我就是没扔。一支笔，一支笔而已。
>
> 但我不后悔。

**改法**：保留"但"最重的两处（它承担反转的地方），其余换词、删转折、或把句子改成动作——让每个转折各干各的：

> 我没谢她。她也没提。但从那以后，数学卷子我都会多看两眼。
>
> 这事我没问过。也不敢问。
>
> 那支笔我一直留着。一支笔，一支笔而已。
>
> 我不后悔。

**解析**：
- **换词**："但我从那以后"→"但从那以后"，同一个意思，节奏变了。
- **删转折**："但我没问"→"这事我没问过"——短句直接并列，比"但"更有力（"光亮，饱满"式）。
- **保留**：如果"但"后面接的是全篇唯一一次真正的反转（比如表白），那它就该留下来。红线是密度，不是次数——同一篇里"但"只出现 3 次和出现 34 次，前者是口头禅，后者是卡带。

**判别口诀**：一个词大面积出现时，逐个问"删掉它句子还成不成立"。大半删掉后依然成立，那些就是复读；删掉后句子塌了的那几处，是真正的转折，留下。
