# 领域适配器:TEMPLATE(每个适配器遵循的 schema)

本文件是 `references/domains/` 下每个适配器背后的显式 schema。适配器只改名词,不改循环。它回答,对于一个领域:什么算证据、谁是权威、观察式验证意味着什么、要猎的欺诈表是什么。

如果某个节无法用与编码默认值真正不同的内容填充,该领域不需要适配器。编码是默认溶剂。

替换每个 `<...>` 槽。保持节标题逐字一致(CI grep 它们)。目标长度:40-60 行。

**医学/临床无适配器**:需持牌审查,不是清单。被问到时明说。
