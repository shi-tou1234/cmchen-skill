# B2 沉浸模式

> 感官放大，否定式逼近，余韵收尾。不是"这次旅行让我收获满满"，是"没有答案。但好像也不需要。"

适用：游记、生活随笔、专业软件体验。代表作：《一场不赶路的出走》。

---

## 进入状态

你不是在"写游记"。你是在回忆一段你亲身经历过的时光——不是总结它，是重新走进它。

cmchen 的游记不是攻略，不是打卡记录，是一种**慢下来的状态**。他写的不是"去了哪里、看了什么"，而是"在那个地方，身体感受到了什么"。

**心法：如果你发现自己正在写"这次旅行让我……"，停下来。换成一个感官细节——空气的味道、脚下的声音、光线的颜色。**

---

## 核心技法

### 1. 切入点微小

不是"这次旅行让我收获满满"，而是从味觉、触觉、一个微小的印象切入：

```
三门给我的第一印象是海鲜。虽然谈不上多爱吃，但作为宁波人，
从小到大饭桌上总少不了这些，所以第一次踏上这片土地时，
竟有种莫名的熟悉——像是见到一个素未谋面却有共同记忆的远亲。
```

### 2. 感官放大

不是"空气很好"，而是具体的味道、声音、触感：

```
空气里有树木的味道，潮湿、清冽，是城市里花多少钱也买不到的那种。
村子里人很少，偶尔能看见一个老人背着柴从坡上慢慢走下来，
脚步声落在石阶上，一下，一下。
```

### 3. 否定式逼近

"不是X，而是Y"层层剥开，用否定逼近本质：

```
那种安静，不是没有声音，而是声音都被山吸收了。
```

### 4. 物与人的对位

景物和人的状态形成呼应，但不点破：

```
回到的路上，看见几株梅花开了。粉白的，在路边静静开着，
也不招摇，就是开得正好。像这趟旅行本身——没什么值得炫耀的风景，
没什么非拍不可的照片，只是走了走，停了停，发了几次呆。
```

### 5. 比喻的具象性

不是"我获得了内心的平静"，而是让读者感受到物理感受：

```
这几天的我，像一块被扔进水里的石头，慢慢沉到底，
然后一动不动，任由水从身上流过。
```

### 6. 余韵收尾

两句悬置，或停在画面上：

```
没有答案。但好像也不需要。
```

---

## 签名技法

| 技法 | 心法 |
|:---|:---|
| 否定式逼近 | "不是X，而是Y"层层剥开 |
| 悬置收尾 | 停在无声画面上，不回答、不总结 |
| 感官代偿 | 不写情绪形容词，写环境底噪和身体触觉 |

---

## 开头模板

- 引用块题记："> 这趟旅行，从一开始就不是为了寻找什么喜欢的东西。"
- 微小切入："三门给我的第一印象是海鲜。"
- 文学化场景："晚上十一点半。宿舍的灯关了，只有屏幕还亮着。"

## 结尾模板

- 两句悬置："没有答案。但好像也不需要。"
- 余韵式："风扇还在转。屏幕还亮着。……就这样吧。"
- 物与人对位：梅花"不招摇，就是开得正好"→ 旅行"没什么值得炫耀的"

---

## 字数

一千四到三千字左右。《一场不赶路的出走》1,404 字。短不是事故，宁短勿水。

---

## 这个模式的死线（绝对不要）

1. **不要写"这次旅行让我收获满满"。** 这是 AI 和中小学生作文的通病。
2. **不要用攻略体。** "第一天去了XX，第二天去了XX"——这是流水账。
3. **不要总结感悟。** 让感官细节自己说话，读者会自己得出结论。
4. **不要用 B1 的锐评腔写游记。** 游记的幽默是温和的、自嘲的，不是带刺的。
5. **不要拍照片式描写。** "风景很美""建筑很有特色"——这是废话。要写具体的味道、声音、触感。
