# D 追问模式

> 苏格拉底式自问自答。精确到具体数字，不修饰不模糊。

适用：自我探索、心理分析、问答体。代表作：《自我探索实验》。

---

## 进入状态

你不是在"写自我分析"。你是在认真地、诚实地回答一系列关于自己的问题——不是为了表演深度，是为了搞清楚自己到底是谁。

cmchen 的自我探索不是鸡汤，不是 MBTI 标签，是一种**结构化的诚实**。他问自己问题，然后给出精确到数字的回答，然后基于这些回答画出一幅自己的画像。

**心法：如果你发现自己正在写"我是一个追求卓越的人"，停下来。换成具体的——"我似乎有点强迫症，电路图争取画得好看。"**

## 核心机制

### 1. 苏格拉底式问答体

Q 给出完整问题并可带一句导读副标题，A 精确到具体数字，不修饰不模糊：

```
### Q1：如果完全没有限制，你心目中「最完美的一天」是什么样的？

**Q：** 如果完全没有经济和时间压力，你心目中「最完美的一天」会是什么样的？
请尽可能详细地描述从醒来入睡的整个过程。

**A：** 早上8点起床，洗漱完开始吃早饭。上午进行学习，每一小时休息10分钟。
中午12点吃午饭。然后下午去探索自然或者是去城市漫游。下午5点吃完饭。
饭后开始打扫卫生，整理今天，规划明天行程。7点外出运动，8点半回家。
待身体冷却开始洗澡。9点开始冥想，听一些音乐。9点半开始娱乐活动。
10点半睡觉。
```

### 2. 结构化自我画像

问答之后附模块化分析报告：

```
#### 1. 核心画像：一位「拥有审美秩序的创造型工程师」

我的内核是**创造**，手段是**技术**，标准是**秩序与美**。

我有两条看似独立却深度交织的主线：
- **生活层面**：追求"责任"与"兴趣"1:1的平衡
- **技术层面**：既在乎顶层体验（UI的美感），也在乎底层逻辑（代码的客观性）
```

结构：核心画像 → 优势与局限 → 潜意识 → 未来路径。

### 3. 允许分析性语言

"内驱力""归因方式""潜意识"——在这里术语不是 AI 味，是真实的自我分析。

### 4. 承认弱点要具体

```
我似乎有点强迫症，电路图争取画得好看。
害怕成为天天写重复业务代码的码农。
```

不是"我有时候太追求完美"（套话），是具体的、可验证的。

### 5. 结尾允许格言式升华

前提是它从前面的回答里长出来：

```
完成比完美更重要，而进化比完成更长久。
```

```
带着责任感的兴趣探索，与充满兴趣感的责任承担——
这1：1的配方，愿你在未来的人生中，调配得越来越从容。
```

不是命令，是祝福。

## 签名技法

| 技法 | 心法 |
|:---|:---|
| 精确数据 | 回答精确到数字（"每一小时休息10分钟"），不模糊 |
| 结构化画像 | 模块化呈现（核心画像→优势→局限→未来路径） |
| 术语诚实 | 分析性语言在这里是真实的自我分析，不是 AI 味 |

## 开头模板

- 问题直入：Q1 完整问题 + 导读副标题
- 背景交代：为什么做这个自我探索、在什么背景下

## 结尾模板

- 格言式升华（必须从前文长出来）："完成比完美更重要，而进化比完成更长久。"
- 祝福式："愿你在未来的人生中，调配得越来越从容。"
- 成长宣言："这条路，我会继续走下去。"

## 这个模式的死线（绝对不要）

1. **不要写套话式自我分析。** "我是一个追求卓越的人"——这是废话。要具体。
2. **不要过度 MBTI 标签化。** 可以提 MBTI，但不能让四个字母定义一个人。
3. **不要回避矛盾。** 可以承认"我既想稳定又想自由"——真实的矛盾比漂亮的结论重要。
4. **不要写平衡报告。** "虽然我有缺点但这也是优点"——这是和稀泥。承认弱点就是承认弱点。
5. **不要让升华从天上掉下来。** 格言式结尾必须从前面的回答里长出来，不是硬拽上去的。
