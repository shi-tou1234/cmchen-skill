# 博客文章写作 Skill

## 📌 概述

当用户发送 **PPT、PDF、讲义、教材截图** 等学习/知识素材时，自动识别其中的 **核心概念**、**公式推导**、**经典例题讲解**，输出为符合本博客 Markdown 渲染要求的博客文章。

> **核心原则**：不要带图！所有图片内容用文字和公式准确描述。

---

## 📐 本博客 Markdown 渲染规范

### 框架信息
| 项目 | 内容 |
|------|------|
| 框架 | Astro v5 + Content Collections |
| 数学渲染 | **KaTeX**（remark-math + rehype-katex） |
| 代码高亮 | Shiki（one-dark-pro） |
| 自定义语法 | auto-math（中文括号自动检测公式）、ruby注音、spoiler、rainbow文字 |

### 一、Frontmatter

每篇文章必须以 YAML frontmatter 开头：

```yaml
---
title: 文章标题
pubDate: 2026-06-03T12:00:00.000Z
updatedDate: 2026-06-03T12:00:00.000Z
draft: false
description: 文章简短描述（可选）
category: 分类名称
slugId: 文章标识
---
```

**category 常用值**：复变函数、数电、模电、电路分析、电磁场、高数、线代、大物、工具使用、英语、笔记方法

#### 行内公式

```markdown
$$ \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} $$
```

#### 多公式并列
```markdown
$$ u_x = e^x \cos y, \quad u_y = -e^x \sin y $$
$$ v_x = e^x \sin y, \quad v_y = e^x \cos y $$
```

#### 分段函数
```markdown
$$ \oint_C \frac{dz}{(z-z_0)^n} = \begin{cases} 2\pi i, & n = 1 \\ 0, & n \neq 1 \end{cases} $$
```

#### 矩阵
```markdown
$$ \begin{pmatrix} a & b \\ c & d \end{pmatrix} $$
```

```markdown
$$ \sum_{k=1}^n \frac{1}{k^2} = \frac{\pi^2}{6} $$
$$ \int_a^b f(x)\,dx $$
```

## 🔄 转换流程

### Step 1：输入接收
用户发送 PPT / PDF / 讲义 / 教材内容（粘贴文字、拖入文件）

### Step 2：内容识别
从素材中自动识别：

| 类别 | 识别内容 | 输出格式 |
|------|---------|---------|
| 核心概念 | 定义、定理、定律、性质、使用场景 | 标题层级 + `> **定理**` 引用 |
| 公式推导 | 从基本定义逐步推导，标明依据，突出关键技巧 | `$$...$$` 块级公式 + 逻辑连接词 |
| 经典例题 | 题目 + 完整求解 + 最终答案 + 易错点 | `#### 例题 N：标题` |
| 小结与汇总 | 对比表格、公式速查、易错点清单 | 表格 + 分点列表 |

> **多文件处理**：若用户一次提供多个素材文件（如多个 PPT），应将其**合并为同一篇文章**，按逻辑章节组织，而不是每个文件输出独立文章。合并时去除各文件间的重复过渡内容（如重复的章节标题页、"学习目标"页等），保留核心知识内容。跨文件的内容要以递进逻辑衔接（如 8.1→8.2→8.3）。

### Step 3：结构化输出
按以下骨架组织文章：
1. **标题** + **Frontmatter** + **导语**
2. **分节**：概念 → 公式推导 → 例题（概念先行，公式居中，例题收尾）
3. **总结**：核心要点 + 公式速查表 + 易错点提醒 + 解题思路要点

### Step 4：格式检查
- [ ] Frontmatter 完整
- [ ] 公式使用 `$...$`/`$$...$$`
- [ ] 无图片引用
- [ ] 标题层级正确（`#` → `##` → `###` → `####`）
- [ ] 例题格式统一
- [ ] 定理/注意使用 blockquote

## 📝 写作风格指南

1. **推导要有逻辑连接词**：不要罗列公式，用"由...可得"、"代入...得到"、"因为...所以..."
2. **例题要有典型性**：选择体现概念本质或解题技巧的题目（每个二级知识点最多配 1 道例题，避免堆砌）
3. **无图原则**：所有图片信息用文字+公式完整表达。电路图 → 描述连接关系 + 公式标参数；波形图 → 分段函数/条件描述
4. **中文为主**：专业术语可保留英文，如 C-R 方程、KaTeX
5. **重要的结论/易错点**用 `**加粗**` 强调
6. **公式稳健性**：
   - `\angle` 后跟负数易渲染失败，优先用指数形式替代：`U e^{-j120^\circ}` 替代 `U\angle -120^\circ`
   - 希腊字母注意大小写：磁通链用小写 `\psi`（而非大写 `\Psi`），功率因数角用 `\varphi`（而非 `\phi`）
   - 若特定命令渲染异常，换用等价写法兜底（如 `\mathrm{...}` / `\mathit{...}` / 指数形式）
   - **禁止连续 `$$` 块**：两个 `$$...$$` 块之间**必须有文字说明**间隔，不能紧挨相邻。remark-math 解析器会将相邻的 `$$` 块误判为块边界，导致渲染失败。

7. **总结段落**：文章末尾设"总结与注意事项"章节，包含：
   - **核心公式速查表**：用 Markdown 表格列出关键公式及其说明
   - **易错点提醒**：分点列出常见混淆点
   - **解题要点**：给出该章节题目的通用解题思路
