# 📚 博客文章写作 Skill — v1.3

将 **PPT / PDF / 讲义 / 教材截图** 等素材，自动转换为符合本博客渲染要求的 Markdown 博客文章（Astro v5 + KaTeX + Shiki）。

博客有 **两大文章分类**，渲染规范各不相同：

| 分类 | 适用 | 特点 |
|:---|:---|:---|
| **学习笔记** | 课程知识、公式推导、例题讲解 | 公式密集、`:::derivation`、无图、结构严谨 |
| **普通文章** | 随笔、工具推荐、创意写作、开发记录 | 自由格式、可有图片、代码、`:::quote` |

> **核心原则**：学习笔记类文章无图！所有图片内容用文字 + 公式准确描述。

## 它做什么

1. **类型判断** — 自动区分学习笔记 vs 普通文章（及子类型）
2. **内容识别** — 提取核心概念、公式推导、例题、小结
3. **结构化输出** — 按对应分类规范生成文章
4. **格式检查** — 对照各自规范逐项校验

## 博客渲染框架摘要

| 项目 | 内容 |
|------|------|
| 框架 | Astro v5 + Content Collections |
| 公式渲染 | KaTeX（`$...$` 行内 / `$$...$$` 块级，remark-math + rehype-katex） |
| 代码高亮 | Shiki（one-dark-pro，带复制按钮） |
| 自定义组件 | `:::derivation` 可折叠推导、`:::quote` 文学引用、`:::note/tip/important/warning/caution` 提示卡 |
| 图片 | 点击放大 lightbox（仅普通文章） |
| 其他 | auto-math、ruby注音、spoiler、rainbow、GFM 脚注 |
| 公式增强 | remark-auto-math（中文括号自动检测公式） |

## 输出质量约定

- **公式稳健性**：相邻 `$$...$$` 块之间必须有文字间隔，禁止连续排列，避免渲染失败
- **无图原则**：学习笔记中电路图 → `> 电路描述：...`；波形图 → 分段函数；表格 → Markdown 重绘
- **例题有典型性**：每个二级知识点最多配 1-2 道例题（三种格式变体可选），不堆砌
- **总结完整**：文末必含**核心公式速查表 + 易错点提醒 + 解题要点**三件套
- **推导带逻辑**：用"由…可得 / 代入…得到"连接公式；复杂推导用 `:::derivation` 可折叠块
