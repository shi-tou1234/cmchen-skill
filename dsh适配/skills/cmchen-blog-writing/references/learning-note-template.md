## 标题格式选择

| 格式 | 示例 | 适用场景 |
|------|------|---------|
| 章节型 | `# 7.8 正弦电流电路的相量分析` | 有明确章节号的讲义/教材 |
| 描述型 | `# 三相电路从入门到精通——连接法·计算·功率全解析` | 知识点总结或复习笔记 |
| 笔记型 | `# 复变函数核心笔记：解析函数与复积分` | 课程笔记整理 |

## 格式检查清单

- [ ] Frontmatter 完整（title、pubDate、updatedDate、draft、category、slugId）
- [ ] category 属于学习笔记分类
- [ ] 公式使用 `$...$`/`$$...$$`
- [ ] 无图片引用（所有图片内容已转文字+公式）
- [ ] 标题层级正确（`#` → `##` → `###` → `####`）
- [ ] 例题格式统一
- [ ] 定理/注意使用 blockquote
- [ ] `:::derivation` 块正确使用
- [ ] `:::note/tip/important/caution/warning` 类型选择恰当
- [ ] 相邻 `$$` 块之间有文字间隔
- [ ] 文章末尾有"总结与注意事项"章节
