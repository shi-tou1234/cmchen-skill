# S5 个人介绍 / 收获型论文

你正在撰写个人介绍或收获型论文。

个人介绍/收获型论文的核心是**个人叙事、成长线索、思想升华**。它不依赖宏大理论或外部数据，而是以个人的真实经历、思想转变、成长收获为素材，展现思想进步和实践成长。适用于评优评先材料、入党申请、党课心得、奖学金申请、个人总结、思想汇报等。

---

## 进入状态

动笔前问自己三个问题：
1. 这次写作的目的是什么？（申请荣誉？汇报思想？总结成长？）
2. 我最想突出的核心特质是什么？（思想进步？学业优秀？工作突出？）
3. 我的经历中最能体现这个特质的具体事件是什么？

**个人介绍/收获型论文的死线**：不是流水账（不罗列所有经历），不是谦虚模板（不"虽然我还有很多不足"），不是空喊口号（不"我要为人民服务"）。个人介绍是"用事实说话，用细节证明，用真诚打动人"。

## 结构模板

### 评优评先/奖学金申请结构（500-1500 字）

```
标题：《XX申请书》或《XX个人简介》

一、基本信息（视表格要求）
   姓名、班级、政治面貌、职务等

二、思想政治（200-300 字）
   思想转变的关键节点
   对党的认识、政治理论学习情况

三、学业表现（200-300 字）
   学业成绩、学习态度、突出成果

四、工作与实践（200-300 字）
   学生工作、社会实践、志愿服务

五、个人感悟（100-200 字）
   成长与收获

六、未来展望（100 字）
   努力方向
```

### 党课心得/思想汇报结构（1500-3000 字）

```
标题：《党课心得体会——XXX》或《思想汇报》

一、引言（200-300 字）
   什么事件/课程/经历触发了这次思考
   核心感悟是什么

二、认知转变 A（400-500 字）
   从"不了解"到了解
   具体的学习内容和收获

三、认知转变 B（400-500 字）
   从"知道"到到信服
   理论如何与实践结合

四、自我反思（300-400 字）
   对照标准找差距
   具体不足和改进方向

五、行动承诺（300-400 字）
   具体的努力方向
   可操作的计划

六、结语（100-200 字）
   总结 + 表态
```

### 入党申请书结构（2000-3000 字）

```
标题：《入党申请书》

一、对党的认识（500-600 字）
   党的性质、宗旨、历史
   对习近平新时代中国特色社会主义思想的认识

二、入党动机（400-500 字）
   为什么要入党
   思想转变过程

三、个人表现（500-600 字）
   思想政治表现
   学业和工作表现
   实践和志愿服务

四、自我剖析（300-400 字）
   存在的不足
   改进措施

五、表态（200-300 字）
   如果被批准/未被批准的态度
   今后的努力方向
```

### 个人总结/成长报告结构（1500-2500 字）

```
标题：《XXX总结》或《XXX个人成长报告》

一、引言
   时间段 + 总体成长概述

二、思想成长
   思想转变的关键事件和节点

三、学业/工作成长
   具体成果和收获

四、实践成长
   参与的活动和感悟

五、不足与展望
   改进方向和努力目标
```

## 开头范式

### 范式一：时间线式

> 2023年9月，我带着对大学的憧憬走进校门。那时的我，对"入党"二字充满敬畏却不真正理解。一年后的今天，经过党校学习和实践锻炼，我对党的认识从模糊走向清晰……

**适用**：有明确时间跨度的成长叙事。

### 范式二：事件触发式

> 2024年10月，我观看了电影《志愿军》。当银幕上那些年轻的面孔一个个倒下时，我的泪水止不住地流。那一刻，我终于明白了什么是"信仰的力量"……

**适用**：有一个具体事件触发思想转变时。

### 范式三：引用开篇式

> "备豫不虞，为国常道。"这句古语一直激励着我未雨绸缪、不断进步。回顾这一学期的学习和成长……

**适用**：需要一个有力的引语开篇时。

## 正文写法

### 用事实说话

个人介绍的核心原则是"用事实说话"，避免空洞的自我评价。

**错误示范**：
> 我是一个积极上进的人，学习刻苦，工作认真。

**正确示范**：
> 在过去一学年里，我每天坚持早读30分钟，专业课平均成绩从82分提升到92分。作为班级学习委员，我组织了4次考前辅导，帮助5名同学通过了补考。

### 用细节打动人

**示例**：

> 记得第一次上党课，老师问我们："你们为什么要入党？"我当时愣住了，脑子里一片空白。那一刻我意识到，我对党的认识还停留在表面。从那以后，我开始主动阅读《中国共产党简史》，参加了学院组织的党史知识竞赛……

**写法要点**：
1. **具体场景**：第一次上党课、某个下午的谈话
2. **真实感受**：愣住了、一片空白
3. **行动跟进**：开始主动阅读、参加活动
4. **成长变化**：从模糊到清晰

### 用真诚代替谦虚

**错误示范**：
> 虽然我取得了一些成绩，但我知道自己还有很多不足，需要继续努力。

**正确示范**：
> 回顾这一学期，我在学业上取得了进步，但在时间管理上还有待提升。下学期，我计划每周制定学习计划，平衡好学业和学生工作的关系。

**原则**：不回避不足，但要用具体的改进措施代替泛泛的"继续努力"。

## 升华与收尾

### 升华路径

个人介绍/收获型的升华通常走"**个人→集体→时代**"路径：

> 个人的成长离不开组织的培养和社会的支持。作为一名新时代大学生，我深知自己肩负着时代赋予的使命。我将继续努力，不辜负组织的期望，为实现中华民族伟大复兴贡献自己的力量。

### 收尾方式

**申请书收尾**：
> 如果组织批准我的申请，我将更加严格要求自己，以实际行动践行入党誓词。如果组织没有批准我也不会气馁，将继续以党员的标准严格要求自己，争取早日加入党组织。

**心得/总结收尾**：
> 这次党课/这次经历让我深刻认识到，个人的成长只有融入国家和民族的事业中才能焕发出更大的价值。我将带着这份收获，继续前行。

## 格式注意事项

### 评优评先材料
- 严格按表格要求填写，不超出字数
- "简要事迹"部分突出重点，简明扼要
- 使用条目式列举（一、二、三、……）

### 入党申请书
- 标题：入党申请书
- 称谓：敬爱的党组织
- 结尾：请党组织在实践中考验我 / 此致 敬礼
- 署名 + 日期

### 思想汇报
- 标题：思想汇报 或 关于XXX的思想汇报
- 称谓：敬爱的党组织
- 结尾：请党组织审查 / 此致 敬礼
- 署名 + 日期
