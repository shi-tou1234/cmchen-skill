# S2 读后感 / 阅读报告

你正在撰写读后感或阅读报告。

读后感是"以书/文为媒、以感为体"的通用写作类型。核心不是复述内容，而是从文本中提炼出一个核心命题，展开思辨，最终落脚到自身的生命体验和成长启示。适用于思政读书报告、课程读后感、阅读笔记、书评等。

---

## 进入状态

动笔前问自己三个问题：
1. 这本书/这篇文章最核心的思想是什么？（用一个词/一句话概括）
2. 这个思想与我的生命经验有什么交汇点？
3. 我想通过这篇读后感表达什么？（感悟？反思？宣告？）

**读后感的死线**：不是读书笔记（不罗列章节），不是书评（不评价写得好不好），不是读后感（不浮于表面情绪）。读后感是"以书为引子的自我对话"。

## 结构模板

### 标准结构（2000-4000 字）

```
标题：主标题（诗意/哲理性）
副标题：《——读〈书名〉，探寻/思考/感悟……》

一、引言（300-400 字）
   作者与背景简介
   最触动你的核心命题
   你的阅读感受/态度

二、核心思辨 A（500-700 字）
   小标题（从文本中提炼的概念）
   文本引述 + 思辨阐释 + 延伸思考

三、核心思辨 B（500-700 字）
   小标题
   文本引述 + 思辨阐释 + 延伸思考

四、核心思辨 C（500-700 字）
   小标题
   文本引述 + 思辨阐释 + 延伸思考

五、自我实践/生命联系（400-600 字）
   你的真实经历/困惑/转变
   文本思想对你的启发和改变

六、结语（200-300 字）
   回扣核心命题
   诗意收束
```

### 精简结构（1500-2500 字）

```
标题

一、引言：为什么读这本书/这篇文章

二、核心感悟 A

三、核心感悟 B

四、联系自身：我的改变

五、结语
```

## 开头范式

### 范式一：人物切入式

> 史铁生说过："我的职业是生病，业余在写作。"这话像玩笑，其实很沉重。21岁，他被迫坐上轮椅。47岁，他又得了尿毒症，每周三次透析。他的人生被切成一段一段的"病隙"……

**适用**：有鲜明作者形象的作品。通过作者生平引入核心命题。

### 范式二：命题切入式

> 什么是苦难？人能在苦难中实现超越吗？如果可以，路径是什么？史铁生在《病隙碎笔》中以切身的病痛体验，给出了他的回答……

**适用**：哲理性强的作品。直接抛出核心问题。

### 范式三：场景切入式

> 第一次翻开《病隙碎笔》是在高考后那个漫长的暑假。那时候的我，正被一种说不清道不明的空虚感包裹着……

**适用**：读后感中有重要的个人实践段落时。

## 正文写法

### 文本引述与思辨的交织

读后感的核心段落在于"引述→阐释→延伸"的三步跳跃。

**示例**（选自《在病隙中仰望星空》）：

> **直面苦难：主体觉醒是超越苦难的前提。** 请你想象一下，一个21岁的年轻人被突然的疾病束缚在了轮椅之上，任何人的第一反应都是抱怨苍天："为何是我？"是的，史铁生也曾深陷于这种绝望的泥潭。他在《我与地坛》中坦言，最初瘫痪的那些年，他充满了"愤怒、抱怨、委屈和找不到出路的绝望"。但是，史铁生没有沉浸在抱怨之中，他完成了从"为何是我？"到"既然是我，我该如何活？"的认知转变。正如荣格所说，"没有一种觉醒是不带着痛苦的"。

**写法拆解**：
1. 小标题（从文本中提炼的核心命题）
2. 场景还原（让你想象/请你代入）
3. 文本引述（原文或概括）
4. 作者分析（做了什么/想了什么）
5. 理论延伸（引用其他理论支撑）
6. 段落总结（一句话收束）

### 小标题设计

- 命题式：直面苦难：主体觉醒是超越苦难的前提
- 概念式：写作即生命的方式
- 关系式：从个人宿命到群体需求
- 对比式：在无神处寻找神性

## 自我实践段落

这是读后感区别于其他论文的关键段落。它要求真诚地面对自己的生命经验。

**示例**：

> 高考结束前，我想象过暑假无数种快乐的可能，是一种解脱的爽感。但事实是这个漫长的暑假并没有我期待中的精彩，它平淡无味，是那种高压生活突然结束的空虚感。这种心态持续了一个多月，直到有天在书店看见了这本书——《病隙碎笔》……

**写法要点**：
1. **真实**：不编造经历，选真正触动你的片段
2. **具体**：有细节、有场景、有感受
3. **关联**：与文本思想形成对照或印证
4. **成长**：体现阅读前后的变化或深化
5. **不煽情**：用克制的笔调写真实的感受

## 升华与收尾

### 升华路径

> 史铁生在《病隙碎笔》中反映的超越苦难的思想是一口取之不尽的水井，只需有心捞取，便可收获颇丰。他的超越思想早已不单单属于自己，而属于全体受困于现实困境的现代人们。

### 诗意收尾

> 身处黑暗，但史铁生却始终仰望光明。这，或许就是超越苦难所能抵达的最高哲学——在病隙中，依然仰望星空。

**收尾原则**：回扣标题意象，形成闭环。结尾的意象/金句最好在引言或正文中已有铺垫。

## 质检清单

- [ ] 标题有诗意/哲理性，不直白
- [ ] 引言包含作者简介、核心命题、阅读态度
- [ ] 正文分 3-4 个思辨部分，每部分有小标题
- [ ] 有文本引述（直接引用或概括）
- [ ] 有理论延伸（不限于文本本身）
- [ ] 有真实的自我实践/生命联系段落
- [ ] 结语回扣标题意象，有诗意
- [ ] 不是读书笔记、不是书评、不是泛泛的读后感
- [ ] 字数达标
