# S3 数据分析 / 调研报告

你正在撰写数据分析或调研报告。

数据分析报告的核心特征是**数据支撑 + 多维分析 + 对话语气**。它不是纯粹的学术论文，而是面向同学、带有交流感的展示文本。适用于社会实践报告、课堂展示、调研分析、数据分析作业、问卷调查报告等。

---

## 进入状态

动笔前问自己三个问题：
1. 这次调研/分析的核心发现是什么？（用一句话概括）
2. 受众是谁？（同学、老师、评委）
3. 你希望他们看完后做什么？（思考？行动？改变认知？）

**数据分析报告的死线**：不是社论（不对受众说话），不是学术报告（不堆砌理论），不是个人日记（不只有自我表达）。数据分析报告是"用数据和逻辑说服人，用真诚和温度打动人"。

## 结构模板

### 发言稿/演讲稿结构（1500-2500 字）

```
标题：设问式/现象式标题

开场白（200-300 字）
   问候 + 现象引入 + 核心问题抛出
   "各位同学，大家好！最近在小红书上刷到一些这样的帖子……"

一、现象与趋势（300-400 字）
   数据呈现 + 趋势描述
   "先看现象与趋势。第一，结婚登记数量下降了……"

二、维度 A 分析（400-500 字）
   小标题
   数据 + 分析 + 案例

三、维度 B 分析（400-500 字）
   小标题
   数据 + 分析 + 案例

四、维度 C 分析（400-500 字）
   小标题
   数据 + 分析 + 案例

五、回应与对策（300-400 字）
   国家/社会/个人层面的回应

六、结语（200-300 字）
   总结 + 呼吁 + 致谢
   "谢谢大家！"
```

### 调研分析报告结构（2000-3000 字）

```
标题
摘要（可选）

一、引言
   调研背景 + 调研方法 + 核心发现

二、调研数据概览
   样本描述 + 关键数据

三、维度分析 A
四、维度分析 B
五、维度分析 C

六、对策建议

七、结语

参考文献（如有）
```

### 数据分析短文结构（1000-2000 字）

```
标题

一、数据呈现
   核心数据 + 可视化描述

二、数据分析
   数据背后的原因/趋势

三、结论与启示
   数据告诉我们什么
```

## 开头范式

### 范式一：热点引入式

> 各位同学，大家好！最近在小红书上刷到一些这样的帖子，宣称不结婚不生子才是正确的决定。那么我们今天就跟大家聊一聊这个热门话题：为什么我们号称不想结婚生子？

**适用**：有社会热点/网络现象可引用的主题。

### 范式二：数据冲击式

> 我们问了 214 位 18-35 岁的年轻人："你还想结婚生孩子吗？"答案里没有标准答案，只有真实的生活困境、自由的渴望，和一点点无奈。

**适用**：有自主调研数据的报告。

### 范式三：问题导入式

> 结婚和不结婚本身是一个选择，这没有对错，我们只是从数据层面分析这背后的原因。

**适用**：需要客观中立立场的主题。

## 正文写法

### 数据呈现与分析

数据分析报告的核心武器是数据。数据不是装饰，是论据。

**数据呈现方式**：
1. **直接引用**："调查显示，85%的受访者认为经济压力是最大拦路虎。"
2. **对比呈现**："62%觉得婚育不是人生必选项，而只有8%认为仍是必经之路。"
3. **趋势描述**："结婚登记数量下降了，二胎家庭变少，一胎家庭变多。"

**数据后必须有分析**：
> 85%的人说：经济压力是最大拦路虎。这不是一个抽象的数字。它意味着，在座的各位同学，十年后走进社会时，面临的第一个人生选择题不是"结不结婚"，而是"租不租得起房、养不养得起娃"。

### 多维分析框架

数据分析报告通常从 2-3 个维度展开分析：

| 维度 | 常用分析角度 |
|:---|:---|
| 经济维度 | 住房成本、教育成本、就业压力、收入预期 |
| 文化维度 | 价值观转变、个人主义、女性独立、婚恋观多元化 |
| 心理维度 | 风险规避、自我决定理论、防御式宣称 |
| 政策维度 | 生育政策、婚假产假、托育补贴、职场保障 |
| 社会维度 | 人口结构、代际差异、城乡差异 |

### 对话语气

数据分析报告（尤其是发言稿）需要与受众保持对话感：

**常用对话句式**：
- "大家看，其实各地已经出台了许多政策来改善这一现象……"
- "我们会有以下症状……"
- "那我们能做什么？"
- "这不是一个抽象的数字。它意味着……"
- "说真的，我以前一直以为……"

**语气原则**：不居高临下，不道德审判，不喊口号。用"我们"代替"你们"，用"分析"代替"批判"。

---

## 数据可视化描述

当无法插入图表时，用文字进行数据可视化描述：

**常用描述方式**：
- 条形图式："A选项占85%，B选项占68%，C选项占52%"
- 饼图式："其中经济压力占42%，个人自由占28%，婚姻风险占18%"
- 趋势线式："从2010年到2020年，总和生育率从1.18降至1.30"
- 对比表式："一线城市房价收入比18.7倍，二线城市12.5倍"

---

## 升华与收尾

### 升华路径

数据分析报告的升华通常走"**现象→结构→选择**"路径：

> 结不结、什么时候结、生不生、怎么生，本质是人生资源的配置题：时间、情感、金钱、精力、身份成长的组合。了解结构性因素（成本、政策）、文化与心理机制（价值观、风险感、内外动机），你们就能更从容地说："这是我想清楚后做出的阶段性选择"，而不是被时代推着走。

### 收尾方式

**发言稿收尾**：
> 愿你们保留热爱，也练就清醒；允许自己改变，也敢于负责当下。谢谢大家！

**调研报告收尾**：
> 综上所述，XX 现象是多重因素共同作用的结果，需要从制度创新、文化重构和社会支持三个层面协同发力。

- [ ] 数据后有分析，不是只罗列数字
- [ ] 从 2-3 个维度展开分析
- [ ] 语气真诚，不居高临下
- [ ] 有回应/对策部分
- [ ] 结语有升华，有呼吁
- [ ] 字数达标
