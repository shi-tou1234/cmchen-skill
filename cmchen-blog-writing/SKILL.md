# 博客文章写作 Skill

## 📌 概述

当用户发送 **PPT、PDF、讲义、教材截图** 等学习/知识素材时，自动识别其中的 **核心概念**、**公式推导**、**经典例题讲解**，输出为符合本博客 Markdown 渲染要求的博客文章。

> **核心原则**：学习笔记类文章不要带图！所有图片内容用文字和公式准确描述。

---

## 🏷️ 文章分类体系

本博客文章分为 **两大分类**，渲染规范各不相同：

### 分类一：学习笔记

| 属性 | 说明 |
|------|------|
| `category` | 具体学科：`电路`、`高数`、`数电`、`大物`、`复变函数`、`英语笔记` |
| `categories`（自动） | 系统自动添加 `学习笔记` 作为一级分类 |
| 特点 | 公式密集、结构严谨、`:::derivation` 推导块、例题+解答、总结速查 |
| 详细规范 | `references/learning-note-template.md` |
| 完整示例 | `现有例子.md`（正弦电流电路分析，504 行） |

> **分类自动补全**：当 `category` 属于 `{电路, 高数, 数电, 大物, 复变函数, 英语笔记}` 之一时，系统自动将其归入 `学习笔记` 父分类。

### 分类二：普通文章

| 子类型 | `category` | 特点 | 模板 |
|--------|-----------|------|------|
| 随笔 | `随笔` | 个人经历、游记、Q&A、可有图片 | `references/regular-article-template.md` → 随笔 |
| 工具使用 | `工具使用` | 工具推荐列表、可有截图 | `references/regular-article-template.md` → 工具使用 |
| 创意写作 | `写在这里` | 故事、小说、`:::quote` | `references/regular-article-template.md` → 创意写作 |
| 开发记录 | 自定义 | 代码为主、技术记录 | `references/regular-article-template.md` → 开发记录 |

## 📐 共享渲染规范

> 详细的格式速查见 `references/rendering-formats.md`

### Frontmatter

```yaml
---
title: 文章标题
pubDate: 2026-06-03T12:00:00.000Z
updatedDate: 2026-06-03T12:00:00.000Z
draft: false
description: 文章简短描述（可选）
category: 分类名称
slugId: 文章标识
---
```

**可选字段**：`categories`（数组）、`image`（封面图，仅普通文章）、`pinned`（置顶）

### 常用渲染组件

| 组件 | 语法 | 用途 |
|------|------|------|
| 提示框 | `:::note/tip/important/warning/caution` | 彩色提示卡片 |
| 自定义标题提示 | `:::tip[自定义标题]` | 带自定义标题的提示 |
| 文学引用 | `:::quote` | 散文/故事引用块 |
| 推导块 | `:::derivation` | 可折叠公式推导 |
| 下划线 | `++文本++` | 下划线标记 |
| 模糊/剧透 | `!!文本!!` | 点击显示 |
| 彩虹文字 | `==文本==` | 彩虹渐变 |
| 注音 | `{汉字}(拼音)` | 拼音注音 |
| 音乐卡片 | `::music{id="..."}` | 网易云音乐嵌入 |
| GitHub 卡片 | `::github{repo="..."}` | GitHub 仓库展示 |
| 公式 | `$...$` / `$$...$$` | KaTeX 数学公式 |
| 代码高亮 | ` ```lang ` | Shiki 语法高亮 |
| 脚注 | `[^1]` | GFM 脚注 |
| 图片 | `![alt](url)` | 点击放大 lightbox（仅普通文章） |
| 分隔线 | `---` 或 `* * *` | 章节分隔 |

### 结构骨架

```
# 标题
> **导语**...
* * *
## 目录（可选）
* * *
## 一、 概念
### 1.1 子标题
**1. 定义**
$$ 公式 $$
> **定理**...
:::
**推导说明**...
:::
#### 例题 1
**解：**...
* * *
## 二、 下一概念
...
* * *
## 三、 总结与注意事项
### 3.1 核心公式速查
### 3.2 易错点提醒
### 3.3 解题要点
```

### 公式稳健性

- `\angle` 后跟负数易渲染失败，优先用指数形式替代：`U e^{-j120^\circ}` 替代 `U\angle -120^\circ`
- 希腊字母注意大小写：磁通链用小写 `\psi`（而非大写 `\Psi`），功率因数角用 `\varphi`（而非 `\phi`）
- 若特定命令渲染异常，换用等价写法兜底（如 `\mathrm{...}` / `\mathit{...}` / 指数形式）
- **禁止连续 `$$` 块**：两个 `$$...$$` 块之间**必须有文字说明**间隔，不能紧挨相邻。remark-math 解析器会将相邻的 `$$` 块误判为块边界，导致渲染失败。

## 📝 普通文章规范

> 完整模板见 `references/regular-article-template.md`

### 随笔（category: 随笔）

- 自由分段，可有图片
- 第一人称、口语化
- 可用 `:::quote` 文学引用
- 可用 Q&A 自问自答格式

### 工具使用（category: 工具使用）

- 列表为主（`*` 无序列表）
- 可有截图
- 口语化、推荐语气

### 创意写作（category: 写在这里）

- `#####` 日期标题
- `:::quote` 文学引用
- 叙事性、文学性

### 开发记录（category: 自定义）

- 代码块为主
- 技术性、记录性

## 🔄 转换流程

### Step 1：判断文章类型

| 判断条件 | 类型 |
|---------|------|
| PPT/PDF/讲义，课程知识、公式推导 | **学习笔记** |
| 个人经历、游记、情感记录 | **普通文章 → 随笔** |
| 工具/网站推荐 | **普通文章 → 工具使用** |
| 故事、小说、创作 | **普通文章 → 创意写作** |
| 项目开发过程 | **普通文章 → 开发记录** |

### Step 2：按对应规范生成

- 学习笔记 → `references/learning-note-template.md`
- 普通文章 → `references/regular-article-template.md`

### Step 3：格式检查

- 学习笔记检查清单 → `references/learning-note-template.md` 末尾
- 普通文章检查清单 → `references/regular-article-template.md` 末尾
