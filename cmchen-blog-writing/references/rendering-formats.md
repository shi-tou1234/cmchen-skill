# 渲染格式速查表

> 本博客支持的所有 Markdown 格式与自定义扩展语法。每种格式给出语法和渲染效果，方便查阅复制。

---

## 一、标准 Markdown 格式

### 1.1 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 1.2 文本样式

```markdown
**粗体文本**
*斜体文本*
~~删除线文本~~
```

**粗体文本**

*斜体文本*

~~删除线文本~~

### 1.3 链接

```markdown
[GitHub](https://github.com)
```

[GitHub](https://github.com)

### 1.4 图片

```markdown
![图片描述](图片URL)
```

- 点击可放大（lightbox）
- 支持 `loading="eager"` 自动预加载
- **仅普通文章使用，学习笔记中禁止使用**

### 1.5 引用

```markdown
> 外层引用
> > 内层引用
> > > 更深层引用
```

> 外层引用
> > 内层引用
> > > 更深层引用

### 1.6 列表

**无序列表：**

```markdown
- 列表项 1
- 列表项 2
  - 嵌套列表项
- 列表项 3
```

- 列表项 1
- 列表项 2
  - 嵌套列表项
- 列表项 3

**有序列表：**

```markdown
1. 第一步
2. 第二步
3. 第三步
```

1. 第一步
2. 第二步
3. 第三步

**任务列表：**

```markdown
- [x] 已完成的任务
- [ ] 待完成的任务
```

- [x] 已完成的任务
- [ ] 待完成的任务

### 1.7 代码

**行内代码：**

```markdown
使用 `console.log()` 输出调试信息
```

使用 `console.log()` 输出调试信息

**代码块：**

````markdown
```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```
````

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

### 1.8 表格

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容1 | 内容2 | 内容3 |
```

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容1 | 内容2 | 内容3 |

### 1.9 分隔线

```markdown
---
```

或

```markdown
* * *
```

### 1.10 脚注

```markdown
这里有一个脚注[^1]，还有一个[^2]。

[^1]: 这是第一个脚注的内容。
[^2]: 这是第二个脚注的内容。
```

这里有一个脚注[^1]，还有一个[^2]。

[^1]: 这是第一个脚注的内容。
[^2]: 这是第二个脚注的内容。

### 1.11 数学公式

**行内公式：**

```markdown
质能方程 $E = mc^2$
```

质能方程 $E = mc^2$

**块级公式：**

```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

### 1.12 HTML 混排

```markdown
<details>
<summary>点击展开</summary>

这里是展开后的内容，支持 Markdown 语法。

</details>
```

<details>
<summary>点击展开</summary>

这里是展开后的内容，支持 Markdown 语法。

</details>

## 二、自定义扩展格式

以下格式是本博客在标准 Markdown 基础上扩展的自定义语法，由 remark/rehype 插件实现。

### 2.1 下划线文本 `++文本++`

```markdown
++这是下划线文本++
```

++这是下划线文本++

### 2.2 模糊/剧透文本 `!!文本!!`

```markdown
!!这是模糊文本，悬停或点击后显示!!
```

!!这是模糊文本，悬停或点击后显示!!

### 2.3 彩虹文字 `==文本==`

```markdown
==这是彩虹文字==
```

==这是彩虹文字==

### 2.4 拼音注音 `{汉字}(拼音)`

```markdown
{汉字}(hàn|zì)
```

{汉字}(hàn|zì)

也支持逐字注音：

```markdown
{博客}(bó|kè)
```

{博客}(bó|kè)

### 2.5 提示框 `:::type`

```markdown
:::note
这是一条 **注意** 信息。
:::

:::tip
这是一条 **提示** 信息。
:::

:::important
这是一条 **重要** 信息。
:::

:::warning
这是一条 **警告** 信息。
:::

:::caution
这是一条 **危险** 信息。
:::
```

:::note
这是一条 **注意** 信息。
:::

:::tip
这是一条 **提示** 信息。
:::

:::important
这是一条 **重要** 信息。
:::

:::warning
这是一条 **警告** 信息。
:::

:::caution
这是一条 **危险** 信息。
:::

**自定义标题：**

```markdown
:::tip[自定义标题]
这里可以自定义提示框的标题文字。
:::
```

:::tip[自定义标题]
这里可以自定义提示框的标题文字。
:::

### 2.6 引用卡片 `:::quote`

```markdown
:::quote
人生得意须尽欢，莫使金樽空对月。

<br><right>—— 李白《将进酒》</right>
:::
```

:::quote
人生得意须尽欢，莫使金樽空对月。

<br><right>—— 李白《将进酒》</right>
:::

### 2.7 推导容器 `:::derivation`

```markdown
:::derivation
**推导过程：**

这里填写推导内容，发布后以悬浮浮层形式展示。
:::
```

:::derivation
**推导过程：**

这里填写推导内容，发布后以悬浮浮层形式展示。
:::

> **渲染行为**：推导块默认隐藏，客户端脚本自动绑定到前一个公式节点——hover（桌面）/ click（移动端）时弹出浮层展示。

### 2.8 音乐卡片 `::music{id="..."}`

```markdown
::music{id="22707008"}
```

::music{id="22707008"}

### 2.9 GitHub 卡片 `::github{repo="..."}`

```markdown
::github{repo="withastro/astro"}
```

::github{repo="withastro/astro"}
